### 1.3 实现机制

#### 1.3.1 i18n 配置 ([i18n.ts](file:///Users/y_sunshine/Documents/svgcodetopng/i18n.ts))

```typescript
const locales = ['en', 'ko'];

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale;
  
  if (!locale || locale === 'en') {
    locale = 'en';
  }
  
  if (!locales.includes(locale)) {
    locale = 'en';
  }

  return {
    locale,
    messages: (await import(`./messages/${locale}.json`)).default
  };
});
```

**关键点:**
- `locales` 数组定义支持的语言
- `requestLocale` 从 URL 参数获取语言
- 动态导入对应的 JSON 翻译文件
- 默认语言为英语

#### 1.3.2 中间件配置 ([middleware.ts](file:///Users/y_sunshine/Documents/svgcodetopng/middleware.ts))

```typescript
export default createMiddleware({
  locales: ['en', 'ko'],
  defaultLocale: 'en',
  localePrefix: 'always'
});

export const config = {
  matcher: ['/((?!api|_next/static|_next/image|favicon.ico|logo.svg|robots.txt|sitemap.xml).*)'],
};
```

**关键点:**
- `localePrefix: 'always'` - 所有 URL 都显示语言前缀
- `/` 重定向到 `/en`
- `/ko` 显示韩文内容
- `matcher` 排除静态文件和 API 路由

```typescript
'use client';

import { useState } from 'react';
import { useRouter, usePathname } from 'next/navigation';
import { Globe, ChevronDown } from 'lucide-react';

const languages = [
  { code: 'en', name: 'English', flag: '🇺🇸' },
  { code: 'ko', name: '한국어', flag: '🇰🇷' },
  { code: 'ja', name: '日本語', flag: '🇯🇵' },
  { code: 'zh', name: '中文', flag: '🇨🇳' },
  { code: 'es', name: 'Español', flag: '🇪🇸' },
  { code: 'fr', name: 'Français', flag: '🇫🇷' },
  { code: 'de', name: 'Deutsch', flag: '🇩🇪' },
];

export default function LanguageSwitcher() {
  const router = useRouter();
  const pathname = usePathname();
  const [isOpen, setIsOpen] = useState(false);

  const getCurrentLanguage = () => {
    const segments = pathname.split('/').filter(Boolean);
    const locale = segments[0];
    return languages.find(lang => lang.code === locale) || languages[0];
  };

  const currentLanguage = getCurrentLanguage();

  const switchLanguage = (newLang: string) => {
    setIsOpen(false);
    try {
      const targetUrl = `/${newLang}`;
      window.location.href = targetUrl;
    } catch (error) {
      console.error('Language switch failed:', error);
      router.push(`/${newLang}`);
    }
  };

  return (
    <div className="relative">
      <button
        onClick={() => setIsOpen(!isOpen)}
        className="flex items-center gap-2 px-3 py-2 text-sm font-medium text-gray-700 dark:text-gray-300 hover:text-gray-900 dark:hover:text-white transition-colors rounded-md hover:bg-gray-100 dark:hover:bg-gray-800"
        aria-label="Switch language"
      >
        <Globe className="w-4 h-4" />
        <span className="hidden sm:inline">{currentLanguage.flag}</span>
        <span className="hidden md:inline">{currentLanguage.name}</span>
        <ChevronDown className="w-4 h-4" />
      </button>

      {isOpen && (
        <div className="absolute right-0 mt-2 w-48 bg-white dark:bg-gray-800 rounded-md shadow-lg ring-1 ring-black ring-opacity-5 z-50">
          {languages.map((lang) => (
            <button
              key={lang.code}
              onClick={() => switchLanguage(lang.code)}
              className={`flex items-center w-full px-4 py-2 text-sm transition-colors ${
                lang.code === currentLanguage.code
                  ? 'bg-blue-50 dark:bg-blue-900/30 text-blue-600 dark:text-blue-400'
                  : 'text-gray-700 dark:text-gray-300 hover:bg-gray-100 dark:hover:bg-gray-700'
              }`}
            >
              <span className="mr-2">{lang.flag}</span>
              <span>{lang.name}</span>
              {lang.code === currentLanguage.code && (
                <span className="ml-auto text-blue-600 dark:text-blue-400">✓</span>
              )}
            </button>
          ))}
        </div>
      )}
    </div>
  );
}
```

## 4. 最佳实践

### 4.1 翻译质量保证

#### 4.1.1 保持 Key 一致性
- 所有语言的 JSON 文件必须使用相同的 key 结构
- 使用嵌套结构组织相关翻译
- 避免在 key 中包含硬编码的文本

**好的示例:**
```json
{
  "navigation": {
    "home": "Home",
    "about": "About"
  }
}
```

**不好的示例:**
```json
{
  "navigation_home": "Home",
  "navigation_about_us": "About"
}
```

#### 4.1.2 使用描述性 Key
- Key 应该描述内容的用途,而不是具体的文本
- 使用点号分隔的命名空间

**好的示例:**
```json
{
  "converter.downloadButton": "Download PNG"
}
```

**不好的示例:**
```json
{
  "downloadPng": "Download PNG"
}
```

#### 4.1.3 处理复数和变量
使用 next-intl 的插值功能:

```json
{
  "welcome": "Welcome, {name}!",
  "itemsCount": "You have {count, plural, =0 {no items} one {# item} other {# items}}",
  "fileSize": "File size: {size, number, ::.##} MB"
}
```

在组件中使用:
```typescript
t('welcome', { name: 'John' })
```

## 5. 注意事项

### 5.1 常见问题

#### 5.1.1 翻译文件格式错误
**问题:** JSON 语法错误导致应用崩溃

**解决方案:**
- 使用 JSON 验证工具检查语法
- 确保所有引号、逗号、括号正确
- 使用 VS Code 的 JSON 格式化功能

#### 5.1.2 缺少翻译 Key
**问题:** 某些语言的翻译文件缺少 key,导致显示 key 本身

**解决方案:**
- 创建翻译检查脚本
- 使用 TypeScript 类型检查
- 在开发环境中显示缺失的翻译

```typescript
// types/i18n.ts
export type TranslationKeys = typeof import('../messages/en.json');

// 在组件中使用类型检查
const t = useTranslations<TranslationKeys>('hero');
```

#### 5.1.3 语言切换后 URL 不更新
**问题:** 切换语言后 URL 没有正确更新

**解决方案:**
- 使用 `window.location.href` 强制刷新
- 确保中间件配置正确
- 检查路由重写规则

#### 5.1.4 RTL 语言支持
**问题:** 阿拉伯语等 RTL 语言显示不正确

**解决方案:**
- 在 HTML 标签中设置 `dir` 属性
- 使用 Tailwind 的 RTL 支持
- 测试所有组件在 RTL 模式下的显示

```typescript
// app/[locale]/layout.tsx
const lang = getLanguageByCode(locale);
return (
  <html lang={locale} dir={lang.direction}>
    ...
  </html>
);
```
