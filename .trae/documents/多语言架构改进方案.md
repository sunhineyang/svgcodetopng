# 多语言架构改进方案

## 问题分析

刚才添加日语时遇到的核心问题：**翻译 key 不匹配**

**问题详情：**
- 代码中使用：`t('testimonials.testimonial1.content')`
- 翻译文件中：`testimonials.testimonial1.text`（英文和韩文）
- 导致错误：`MISSING_MESSAGE: Could not resolve 'testimonials.testimonial3.content'`

**根本原因：**
- 创建日语翻译时，错误地使用了 `text` 而不是 `content`
- 没有统一管理翻译 key 的命名规范

---

## 改进方案

### 方案 1：创建统一的语言配置文件（推荐）

**新建文件：** `config/languages.ts`

```typescript
export const supportedLanguages = [
  {
    code: 'en',
    name: 'English',
    flag: '🇺🇸',
    locale: 'en-US',
    direction: 'ltr',
    translationKeys: {
      testimonials: {
        text: 'text',  // 统一使用 text
        author: 'author',
        role: 'role'
      },
      faq: {
        question: 'question',
        answer: 'answer'
      }
    }
  },
  {
    code: 'ko',
    name: '한국어',
    flag: '🇰🇷',
    locale: 'ko-KR',
    direction: 'ltr',
    translationKeys: {
      testimonials: {
        text: 'text',
        author: 'author',
        role: 'role'
      },
      faq: {
        question: 'question',
        answer: 'answer'
      }
    }
  },
  {
    code: 'ja',
    name: '日本語',
    flag: '🇯🇵',
    locale: 'ja-JP',
    direction: 'ltr',
    translationKeys: {
      testimonials: {
        text: 'text',
        author: 'author',
        role: 'role'
      },
      faq: {
        question: 'question',
        answer: 'answer'
      }
    }
  },
];

export const defaultLanguage = 'en';

export function getLanguageByCode(code: string) {
  return supportedLanguages.find(lang => lang.code === code) || supportedLanguages[0];
}

export function getTranslationKey(languageCode: string, category: string, subKey: string) {
  const lang = getLanguageByCode(languageCode);
  return `${category}.${lang.translationKeys[category as keyof typeof lang.translationKeys][subKey as keyof typeof lang.translationKeys[typeof category]]}`;
}
```

**优势：**
- 统一管理所有语言信息
- 定义翻译 key 的命名规范
- 添加新语言时只需修改配置文件
- 避免手动修改多个文件导致的错误

### 方案 2：更新现有翻译文件（备选）

如果不想创建配置文件，可以统一修改现有翻译文件：

**修改内容：**
- `messages/en.json` - 将 `testimonial1.text` 改为 `testimonial1.content`
- `messages/ko.json` - 将 `testimonial1.text` 改为 `testimonial1.content`
- `messages/ja.json` - 将 `testimonial1.text` 改为 `testimonial1.content`

**同样修改：**
- `faq.question1.question` → `faq.question1.question`
- `faq.question1.answer` → `faq.question1.answer`

## 实施步骤（选择方案 1）

### 步骤 1：创建配置文件
- 新建 `config/languages.ts`
- 定义所有支持的语言和翻译 key 规范

### 步骤 2：更新组件使用配置
- 修改 `LanguageSwitcher.tsx` 使用配置文件
- 修改 `app/[locale]/page.tsx` 使用配置文件中的 key

### 步骤 3：统一翻译文件 key
- 修改 `messages/en.json`、`messages/ko.json`、`messages/ja.json`
- 确保所有翻译文件使用相同的 key 结构

---

## 预期效果

1. **添加新语言更简单**：只需修改配置文件和创建翻译文件
2. **避免 key 不匹配**：统一的命名规范确保一致性
3. **易于维护**：所有语言信息集中管理
4. **减少错误**：自动化程度更高，手动干预更少

---

## 推荐方案

**推荐使用方案 1（创建配置文件）**，因为：
- 更符合工程化实践
- 更容易扩展和维护
- 减少人为错误
- 为未来添加更多语言打下良好基础
